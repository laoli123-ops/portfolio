## 개발 방식

```text
현장 인터뷰로 업무 흐름 파악 → 상태/규칙을 문서로 정의 → AI 도구로 구현
→ 테스트로 규칙 검증 → 스테이징 확인 → 마이그레이션 + 배포 → 사용자 피드백 반영
```

각 프로젝트는 `docs/`에 아키텍처·DB 맵·의사결정 기록(Decision Log)을 두고 변경 이력을 관리했습니다.
